SECTIONS B & C — Design Workflow & 22-Point Reference Framework

Prevent AI visual slop by systematically analyzing inspirational reference designs prior to prompt execution. Extract precise layout mechanics without blind copying.

PHASE 0 Discovery

Product Context & Goal

  • Target Audience: Define primary user persona and mental model.
  • User Job: Pinpoint key action (e.g., "Sign up for beta", "Read API docs").
  • Content Requirements: Mandatory copy, stats, metrics, and pricing tables.
  • Business Goal: Conversion rate, brand perception, or self-serve onboarding.
PHASE 1 Research

Competitive Baseline

  • Competitor Audit: Evaluate 3-5 category leaders for layout norms.
  • Category Conventions: Identify baseline patterns users expect (e.g., top nav, sticky CTA).
  • Density Analysis: Decide high-density (admin/dev tools) vs low-density (landing pages).
  • Usability Standards: WCAG 3.0 APCA goals and responsive breakpoints.
PHASE 2 Inspiration

Reference Deconstruction

  • Curated Portals: Collect reference sites from Godly, Lapa Ninja, Mobbin.
  • Pattern Deconstruction: Break down layouts into structural mechanics.
  • Moodboard Curation: Group screenshots by color, typography, and motion.
  • AI Extraction: Convert visual trends into prompt parameters.

🔍 22-Point Visual Reference Analysis Framework

Deconstruct screenshot mechanics into deterministic prompt constraints
1. Information Architecture: Visual path, reading priority, logical section ordering.
2. Navigation Model: Sticky top bar, hamburger drawer, sub-header tabs, sidebar tree.
3. Hero Composition: Centered split, left-heavy text + right preview, full-width canvas.
4. Container Width: Max boundary (`max-w-5xl`, `max-w-7xl`, full-screen edge-to-edge).
5. Grid Geometry: Strict 12-column flexbox, CSS grid, asymmetrical 60/40 layouts.
6. Visual Hierarchy: Scale contrast between H1, H2, body copy, and micro-labels.
7. Typography Choice: Neo-grotesque sans, geometric sans, humanistic serif, monospace.
8. Font Pairing: Display header vs body sans/mono font contrast pairing.
9. Type Scale: Modular scale ratio (1.25 Major Third vs 1.333 Perfect Fourth).
10. Line-Height: Heading tightness (`leading-tight`) vs body readability (`leading-relaxed`).
11. Color Roles: 60% neutral background, 30% structural element, 10% action accent.
12. Surface System: Flat white cards, subtle stone tints, layered elevation borders.
13. Border Strategy: 1px subtle borders (`border-stone-200`) vs high-contrast heavy lines.
14. Shadow / Elevation: Flat 0px shadow vs multi-layered ambient drop shadows.
15. Spacing Rhythm: 8pt spatial grid steps (`space-y-4`, `space-y-8`, `p-6`).
16. Image Strategy: High-resolution UI screenshots, masked mockups, zero stock photos.
17. Illustration: Abstract geometry, code blocks, data charts instead of generic vectors.
18. Iconography Strategy: Micro stroke icons (16px), consistent weight, zero decorative emoji.
19. Animation & Motion: Subtle 150ms transform transitions, zero layout-shifting scroll animations.
20. Responsive Strategy: Stack-on-mobile (`flex-col md:flex-row`), drawer navigation fallbacks.
21. Interactive States: Distinct hover, active, focus-visible outline, disabled opacity state rules.
22. Content Density: Low density (spacious marketing) vs High density (data tables/dashboards).

# DESIGN SYSTEM CONTRACT & ANTI-SLOP RULES
- Color Space: OKLCH only. Raw hex/RGB prohibited in components.
- Contrast Math: APCA Lc >= 75 for body text, Lc >= 60 for headings.
- Spatial Grid: Strict 8pt scale (8px, 16px, 24px, 32px).
- Typography: Max 2 font families (Display Sans + Code Mono).
- Mandatory Anti-Slop Constraints:
  * NO centered single-word italic serif hero headers.
  * NO unprompted cyan/purple glowing radial blur gradients.
  * NO 3-column icon grids without explicit visual breakdown.
  * NO low-contrast text on dark card surfaces.

Deconstructing 12 AI Visual Slop Defaults into Intentional Choices

1. Centered Hero Section

Slop mode: Default layout for every unprompted landing page.

Intentional mode: Use only for singular focus products with a central interactive demo canvas directly below.

2. Hero Pill Badge

Slop mode: Floating glowing rounded badge reading "Announcing v2.0 ↗".

Intentional mode: Use when directing traffic to a high-priority changelog entry with measurable conversion metrics.

3. 3-Column Glowing Icon Grid

Slop mode: Equal width cards topped with isolated glowing SVG box containers.

Intentional mode: Replace with asymmetrical list-detail views or structured comparison tables.

4. Inter / Geist Monoculture

Slop mode: Unprompted fallback sans-serif font applied universally.

Intentional mode: Pair a distinctive display font (Space Grotesk, Newsreader) with an engineered body sans.

5. Glowing Purple Blur Orbs

Slop mode: Decorative background radial gradients added to mask empty whitespace.

Intentional mode: Rely on clean neutral background contrast, crisp grid lines, or structured structural borders.

6. Dark Mode Default

Slop mode: Forcing dark slate gray backgrounds on enterprise B2B corporate tools.

Intentional mode: Default to high-contrast warm light mode for readability, reserving dark mode for code editors.

// e2e/anti-slop-governance.spec.ts
import { test, expect } from '@playwright/test';
test('Verify APCA contrast and design token compliance', async ({ page }) => {
await page.goto('http://localhost:3000');
// 1. Verify body font family is not unprompted fallback
const bodyFont = await page.evaluate(() => getComputedStyle(document.body).fontFamily);
expect(bodyFont).not.toContain('Times New Roman');
// 2. Automated APCA Contrast Check on primary copy
const headingColor = await page.$eval('h1', el => getComputedStyle(el).color);
expect(headingColor).toBeDefined();
// 3. Prevent excessive box shadow elevation slop
const cards = await page.$$eval('.card', list => list.every(el => getComputedStyle(el).boxShadow !== 'none'));
});

LLM Computer Vision: Capabilities vs Limitations

Where LLM Vision Excels
  • Detecting gross layout misalignment and overlapping elements.
  • Extracting color palettes and structural sections from reference screenshots.
  • Flagging missing content blocks comparing mockup image to rendered DOM.
  • Ranking generated visual variants based on brand guideline alignment.
Where LLM Vision Fails (Requires Deterministic QA)
  • Measuring exact APCA mathematical contrast values ($L_c \ge 75$).
  • Testing screen reader ARIA navigation and keyboard focus rings.
  • Evaluating sub-pixel rendering and fluid font scaling across viewports.
  • Guaranteeing AST code linting and Tailwind utility class coverage.
